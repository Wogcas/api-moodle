# api-moodle
 This is an API RESTFul proposal with academic and learning purposes, this API provides methods for other components/services to access a Moodle web service and its functions. 


📦 How to Dockerize the Project
To dockerize the project, navigate to the root level (the rest folder) and run the following commands:
-docker compose build
-docker compose up

🗑️ How to Remove It from Docker
To remove the containers and network created by Docker Compose, execute:
docker compose down
